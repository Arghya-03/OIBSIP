# 🍕 Pizza Delivery – Frontend

A modern pizza ordering frontend built with **React.js** and **Vite** as part of the OASIS INFOBYTE Web Development and Designing Internship.

## 🚀 Features

* 🍕 Pizza dashboard with multiple pizza varieties
* 🧑‍💻 User registration and login
* 📧 Email verification
* 🔐 JWT-based authentication
* 🔑 Forgot password and password reset
* 🧀 Custom pizza builder
* 🥫 Multiple bases, sauces and cheese options
* 🥬 Multiple topping selection
* 🧾 Order summary before payment
* 💳 Razorpay test-mode payment integration
* 📦 Order tracking
* 👨‍💼 Admin login and dashboard
* 📊 Inventory management
* 🔄 Real-time order status updates

## 🛠️ Technologies Used

* React.js
* Vite
* JavaScript
* CSS
* Socket.IO Client
* Razorpay

## 📂 Main Pages

* Home

* Order Tracking
* Admin Login
* Admin Dashboard

## ▶️ Run the Frontend

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The frontend will normally run at:

```text
http://localhost:5173
```
