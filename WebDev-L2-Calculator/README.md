# SimpleCalc – Calculator

A simple and responsive browser-based calculator created using HTML, CSS, and Vanilla JavaScript.

This project is completed as part of the Oasis Infobyte Web Development and Designing Internship – Level 2, Task 1.

## Features

- Addition, subtraction, multiplication, and division
- Decimal number support
- Clear button to reset the calculator
- Delete button to remove the last digit
- Equal button to calculate the result
- Division-by-zero protection
- Operator chaining
- Responsive design for desktop and mobile devices
- Clean and simple user interface
- Uses JavaScript event listeners for button actions

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
