# Temperature Converter

## About the Project

This is a simple and responsive Temperature Converter website created as part of my Oasis Infobyte Web Development and Designing Internship.

The website allows users to enter a temperature and convert it between Celsius, Fahrenheit, and Kelvin.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Convert Celsius to Fahrenheit
- Convert Celsius to Kelvin
- Convert Fahrenheit to Celsius
- Convert Fahrenheit to Kelvin
- Convert Kelvin to Celsius
- Convert Kelvin to Fahrenheit
- Input validation
- Simple and clean user interface
- Responsive design for mobile devices

## How It Works

1. Enter a temperature value.
2. Select the unit to convert from.
3. Select the unit to convert to.
4. Click the **Convert** button.
5. The converted temperature is displayed in the result section.
