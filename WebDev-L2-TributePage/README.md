# Tribute Page – Dr. A. P. J. Abdul Kalam

A responsive tribute webpage dedicated to Dr. A. P. J. Abdul Kalam, highlighting his life, contributions, achievements, and important milestones.

This project is completed as part of the Oasis Infobyte Web Development and Designing Internship – Level 2, Task 2.

## Features

- Clean and professional tribute page
- Responsive design for desktop, tablet, and mobile
- Introduction to Dr. A. P. J. Abdul Kalam
- About section
- Major achievements section
- Important life events timeline
- Inspirational quote section
- Navigation links with smooth scrolling
- Simple scroll effect on the header
- Image section featuring Dr. A. P. J. Abdul Kalam

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
