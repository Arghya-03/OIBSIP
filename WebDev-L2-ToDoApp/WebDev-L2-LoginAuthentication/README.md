# SecureLogin – Login Authentication System

A professional and responsive frontend Login Authentication System built using HTML, CSS, and Vanilla JavaScript.

This project is completed as part of the Oasis Infobyte Web Development and Designing Internship – Level 2, Task 4.

## Features

- User registration
- User login
- Email and password validation
- Password confirmation during registration
- Password visibility toggle
- Password strength indication
- Prevents duplicate email registration
- Displays login and registration error messages
- Successful login dashboard
- Displays logged-in user's information
- Logout functionality
- Login session persistence using Local Storage
- Responsive design for desktop, tablet, and mobile devices
- Clean and professional user interface
- No inline JavaScript event handlers

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Browser Local Storage
