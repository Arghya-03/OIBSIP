# TaskFlow – To-Do Web App

A simple and responsive To-Do Web App created using HTML, CSS, and Vanilla JavaScript.

This project is completed as part of the Oasis Infobyte Web Development and Designing Internship – Level 2, Task 3.

## Features

- Add new tasks
- Add tasks using the Enter key
- Mark tasks as completed
- Unmark completed tasks
- Edit existing tasks
- Delete tasks
- Filter tasks by:
  - All
  - Active
  - Completed
- Shows the number of tasks
- Saves tasks using browser Local Storage
- Tasks remain saved after refreshing the page
- Prevents empty tasks
- Responsive design for desktop and mobile devices
- Clean and simple user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Browser Local Storage
